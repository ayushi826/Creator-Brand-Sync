# 🚀 Creator-Brand Sync
### *AI-Powered Discovery for the Next-Gen House of Brands*

This project is a high-performance prototype built from scratch to solve a core challenge for **Upcoming Brands**: intelligently matching modern Indian creators with specific brand identities using AI and cultural data.

---

## 🌟 Why This Exists
In a "house of brands" model, speed and cultural resonance are everything. This tool replaces manual searching with an **AI-first matching engine** that understands the "raw frequency" and "vibe" of a creator rather than just their follower count. It is designed for a digitally native generation with entirely new expectations.

## ✨ Key Features
*   **AI Vibe-Analysis**: Uses NLP to categorize creators into brand segments like Tech, Fashion, and Lifestyle.
*   **6-Axis Radar Profile**: Visualizes creator strengths across authenticity, reach, momentum, resonance, originality, and community.
*   **Bharat-First Localization**: A "Bharat Edition" toggle that switches the UI to regional contexts, including **INR (₹) currency** and localized naming conventions.
*   **Gamified Engagement**: Includes achievement badges (Bronze to Platinum) to reward and track creator performance.
*   **Dual-Mode Interface**: Fully functional **Dark and Light modes** for a modern user experience.

## 🛠️ Tech Stack
*   **Architecture**: TypeScript-based Monorepo for professional scalability.
*   **Frontend**: React / Next.js styled with Tailwind CSS for a high-contrast "Offbeat" aesthetic.
*   **Backend**: Node.js / Express API server defined with OpenAPI (Swagger) specifications.
*   **Package Management**: **pnpm** (workspaces) for high-efficiency dependency handling.
*   **Development**: Optimized for VS Code and ready for Vercel/Replit deployment.
